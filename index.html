Assessing without the due list

Where the due list could not be brought, an assessment can still be recorded by typing the event code and the species. Press the button below. Both must match the registry exactly or the row will be refused when the file is loaded, which is why the due list is the better way.

Register a nursery

A nursery is registered once and then referred to for years. Where a nursery of the same name already exists in that district, loading this file brings it up to date rather than adding it twice, so it is safe to record one you are unsure about.

Where is my work kept?

In this browser on this phone. It survives closing the browser and switching the phone off. It is lost if the browser data is cleared, if the phone is reset, or if the file is opened in a different browser. Export at the end of every day.
